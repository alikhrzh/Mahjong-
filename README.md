## О проекте

Mahjong Solitaire — это современное браузерное веб-приложение для игры в Маджонг-пасьянс. Проект создавался не как очередной клон классической игры, а как полноценный продукт, ориентированный на возвращаемость пользователя: с авторизацией, облачной историей, статистикой и продуманным UX.

Игра работает полностью в браузере, не требует установки и одинаково удобна как на компьютере, так и на телефоне.

---

## Почему это выделяется на рынке

Большинство существующих сайтов с Маджонгом — это устаревшие Flash-клоны или сайты с рекламой на половину экрана без какого-либо аккаунта и прогресса. Этот проект решает другую задачу:

| Обычные сайты | Этот проект |
|---|---|
| Нет аккаунта, нет прогресса | Magic Link авторизация через Supabase |
| Одна раскладка для всех | Генератор с 3 уровнями сложности и случайным сидом |
| История не сохраняется | Локальная + облачная история прохождений |
| Нет статистики | Таймер, счётчик ходов, процент побед |
| Устаревший дизайн | Tailwind v4, Framer Motion, тёмная/светлая тема |
| Неудобно на телефоне | Адаптивный дизайн, протестирован на мобильных |

Ключевая идея: **игрок всегда знает, куда он развивается**. Видит свои лучшие времена, сравнивает результаты по сложности, возвращается чтобы побить рекорд.

## Функционал

- **Генератор раскладок** — классическая раскладка «Черепаха» с 144 тайлами, генерируется случайный сид для каждой партии. Три уровня сложности: Easy, Medium, Hard — различаются степенью перемешивания колоды.
- **История прохождений** — каждая завершённая партия сохраняется локально (localStorage) и, при авторизации, в облаке (Supabase). История доступна сразу после обновления страницы.
- **Авторизация** — Magic Link через Supabase Auth. Никаких паролей: вводишь email, получаешь ссылку, входишь.
- **Облачный прогресс** — завершённые партии синхронизируются с базой данных для авторизованных пользователей. Работает по принципу local-first: игра никогда не зависает из-за проблем с сетью.
- **Тёмная / светлая тема** — определяется автоматически из системных настроек, переключается вручную.
- **Подсказка** — подсвечивает доступную пару тайлов, если игрок зашёл в тупик.
- **Отмена хода** — откат последнего совершённого хода.
- **Та же раскладка / Новая игра** — можно переиграть тот же сид или сгенерировать случайный.
- **Статистика** — таймер, счётчик ходов, общий счёт побед и поражений.

## Архитектура

Проект построен по принципу **local-first**: вся игровая логика живёт на клиенте в Zustand-сторе и localStorage. Supabase подключается как необязательный слой поверх — для облачной истории и авторизации. Если сеть недоступна или пользователь не авторизован, игра работает в полном объёме.

Это означает нулевую задержку на каждое игровое действие и отсутствие зависимости от аптайма сервера во время игры.

## Адаптивность

Интерфейс протестирован на мобильных устройствах. Игровое поле масштабируется под ширину экрана, кнопки управления удобны для нажатия пальцем, история прокручивается отдельно от доски.

## Будущее продукта

Следующие шаги, которые превратят игру в полноценный сервис:

- **Таблица лидеров** — глобальный рейтинг по лучшему времени для каждого уровня сложности, построенный на уже существующей таблице `completed_games` в Supabase.
- **Ежедневная раскладка** — одна общая раскладка на каждый день для всех пользователей. Создаёт соревновательный мотив вернуться именно сегодня.
- **Профиль игрока** — страница со статистикой: всего партий, процент побед, лучшее время по уровням сложности, серия побед.
- **Новые раскладки** — помимо «Черепахи» добавить Пирамиду, Крест, Дракона. Генератор раскладок уже абстрагирован, расширение минимально по коду.
- **PWA** — установка на телефон как нативное приложение, работа офлайн, push-уведомление о ежедневной раскладке.
- **Монетизация** — подписка для доступа к расширенной статистике и эксклюзивным наборам тайлов (тематические скины).

## Локальный запуск

```bash
# Установить зависимости
pnpm install

# Запустить фронтенд
pnpm --filter @workspace/mahjong-solitaire run dev

# Запустить API-сервер (опционально)
pnpm --filter @workspace/api-server run dev
```

Переменные окружения (опционально, для облачных функций):
```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
DATABASE_URL=...
```
